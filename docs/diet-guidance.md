# 식단 조언과 식품 이미지 기준

작성일: 2026-11-06

## 조언 카드 문구

1. **다양하게 구성해요** — 곡류, 단백질 식품, 채소·과일을 끼니에 나누어 선택해 보세요. 특정 한 가지 음식이나 영양소만으로 식사의 질을 판단하지 않습니다.
2. **달콤한 음료는 줄여봐요** — 단 음료를 자주 마신다면 물이나 무가당 음료로 바꿔보는 것이 실천하기 쉬운 선택입니다.
3. **하루보다 반복을 살펴봐요** — 한 끼나 하루의 기록은 참고 정보입니다. 며칠간의 식사 패턴과 실제 분량을 확인해 조정합니다.

## 기준과 한계

- 보건복지부·한국영양학회 「2025 한국인 영양소 섭취기준」은 에너지 적정비율(탄수화물 50–65%, 단백질 10–20%, 지질 15–30% 에너지)과 총당류 20% 이내, 첨가당 10% 이내 제한 및 가당 음료를 가능한 줄이는 권고를 제시합니다.
- 이 비율은 일반 인구 집단의 참고 기준이지, 페이스핏 이용자 개인의 처방이나 하루 목표로 자동 적용할 숫자가 아닙니다. 나이·질환·임신·수유·운동량 등의 차이가 있으므로 조언 카드에서 목표량을 단정하지 않습니다.
- 음식 사진의 종류·양 추정치는 실제 식품과 양이 다를 수 있습니다. 사용자가 확인·수정한 값만 기록에 반영합니다.
- 질환 관리, 섭식장애, 임신·수유, 성장기 영양 조정은 의료진 또는 영양 전문가와 상의하도록 안내합니다.

## 데이터·표현 기준

- K-FIND 식품 영양성분 데이터는 표준 정보로 검색하고, 식품 선택과 섭취량 확인을 돕는 용도입니다. 포장 제품·조리법·브랜드 차이로 실제 영양값은 다를 수 있습니다.
- 데이터 출처는 사용자가 검색·기록 화면에서 알 수 있게 표시합니다.
- 음식 일러스트는 페이스핏 자체 제작 SVG 픽토그램으로, 사진처럼 보이게 과장하지 않고 음식군을 구분하는 용도로만 씁니다.
