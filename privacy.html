AI 사진 분석 동의 시선택한 식사 사진음식 종류와 분량 추정

식단 서버 저장은 별도 선택 동의를 받아 활성화하며, 동의하지 않으면 새 식단 기록과 사진은 이 브라우저에만 저장됩니다. 서버에 저장한 식단 기록·사진은 운영자 권한 계정에서 볼 수 있고 트레이너 계정에는 공유되지 않습니다. 설정에서 서버 기록 삭제를 요청할 수 있으며, 탈퇴 시 계정 데이터와 식단 사진 저장 객체를 삭제하도록 설계했습니다. 기기 저장 기록은 해당 브라우저 저장소에서 관리합니다.

K-FIND 공식 식품영양성분 데이터의 영양값은 식품의 기준량에 맞춘 참고값입니다. 실제 제품, 조리법, 섭취량에 따라 달라질 수 있으며 사용자가 입력하거나 수정한 양에 따라 추정 합계를 표시합니다.

사진 분석 기능은 현재 서버 설정 및 배포가 완료되기 전까지 꺼져 있으며 사진을 외부로 전송하지 않습니다. 활성화한 뒤에는 별도로 동의한 사진만 OpenAI API로 전송해 음식 종류와 분량을 추정합니다. OpenAI의 API 정책상 API 데이터는 기본적으로 모델 학습에 사용되지 않으며, 기본 악용 모니터링 로그에는 요청 내용이 최대 30일 보관될 수 있습니다(법적·보안상 예외가 있을 수 있음). OpenAI API 데이터 처리 안내를 확인할 수 있습니다. 사진 분석은 선택 사항이며 결과는 부정확할 수 있으므로 사용자가 확인·수정해야 합니다.

트레이너와 운영자 접근

회원이 트레이너 코드를 등록한 경우에만 해당 트레이너가 서버 운동 기록을 볼 수 있습니다. 회원이 대리 작성 권한을 별도로 허용하면 트레이너가 기록을 작성할 수 있습니다. 회원은 권한을 끄거나 연결을 해제할 수 있습니다. 운영자는 서비스 운영을 위해 서버에 저장된 계정·운동 기록·연결 상태를 볼 수 있습니다.

보유와 삭제

서버 정보는 서비스 이용 중 보관하며, 회원이 계정을 탈퇴하면 앱 데이터와 계정 정보를 삭제합니다. 탈퇴 후 1년간 복구용으로 보관하는 기능은 현재 제공하지 않습니다. Supabase의 운영 백업과 로그에는 제공업체가 정한 별도 보유 기간이 적용될 수 있습니다. 기기 내 운동 기록과 시제품 식단 기록·사진은 해당 브라우저의 저장소에 보관됩니다. 브라우저 저장소를 삭제하면 기록을 복구할 수 없습니다.

클라우드 처리와 위치

주 데이터베이스, 인증 서비스와 백업의 선택 리전은 대한민국 서울(ap-northeast-2)입니다. Supabase Pte. Ltd.(싱가포르, privacy@supabase.io)가 클라우드 보관·인증을 처리하고, Supabase, Inc.(미국)는 필요한 기술 지원과 운영에 참여할 수 있습니다. 서비스 운영 로그와 지원 과정의 정보는 서울 밖에서 처리될 수 있습니다.

가입·로그인 인증 메일 발송에는 Resend를 운영하는 Plus Five Five, Inc.(미국)를 이용합니다. 수신 이메일 주소, 발신 주소, 인증 메일 내용(인증 링크 포함), 발송·전달 로그가 Resend를 통해 미국에서 처리·저장됩니다. Resend에서 선택한 도쿄(ap-northeast-1) 리전은 이메일 발송 위치이며 데이터 저장 위치는 미국입니다. Resend는 Free 플랜에서 이메일·로그 데이터를 계정 이용 중 30일 보관하고, 서비스 이용 종료 후 남은 고객 데이터는 최대 90일 안에 삭제한다고 안내합니다. 운동 일지와 신체 정보는 Resend에 보내지 않습니다. 서버 저장을 원하지 않으면 온라인 계정 가입이나 운동 정보 서버 동의를 거부하고 이 기기 전용 기능을 사용할 수 있습니다.
